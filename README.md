# 流动法律咨询的事实澄清与双语转介

咨询点来往记录采用 UTF-8 编码，人物、单位和记录均为合成内容。

| 资料 | 字段 |
| --- | --- |
| `资料/访谈.json` | `id`、`turn`、`voice`、`language`、`heardAt`、`text` |
| `资料/服务站.json` | `id`、`name`、`topic`、`coverage`、`languages`、`access` |
| `资料/人员登记.json` | `id`、`display`、`aliases`、`homeStation` |
| `资料/转介.json` | `id`、`item`、`toStation`、`sentAt`、`basisTurns`、`excerptTurns`、`status`、`arrangement`、`note` |
| `资料/补充.json` | `id`、`recordedAt`、`voice`、`language`、`heardAt`、`text` |
| `资料/词表.json` | `id`、`zh`、`en`、`topic`、`note` |

每份资料是 JSON 数组。记录中的字段值按来源原样保留为字符串，逗号和顿号可以属于字段内容。资料中可能有转述、不同的拼写以及较晚录入的更正。数字及日期在这些文件中沿用各资料自身的含义；原文位置以记录编号及文本范围定位。

Node.js 22 环境下运行以下命令可安装锁定的项目环境、检查素材格式并读取各类资料的数量。

```sh
npm ci --offline --ignore-scripts --no-audit --no-fund
npm test
npm run materials
npm run report
```

`readMaterials` 只读取资料，不解析其中的正文含义。

## 这份工具做什么

`npm run report` 把访谈原话、翻译补记、补充说明与已发出的转介整理成一份中文报告，供接访人员复核。它只做归类、对齐和提示，不作出法律判断，也不替来访者补全事实。报告中每一条判断都能回查到原话编号。

报告分十节：

1. **按事项归入的原话**：每条分句只归入它自己的用词能支持的事项；无法判断时留在“未归入”。
2. **身份与角色**：代问、当事人、被要求签字、实际签字、明确未签、陪同，按事项分别记录。
3. **未归入事项的说法**：接访员和译员的话、假设举例、听来的说法单列，不作为证据。
4. **更正与原始说法**：“前面我讲错了”这种指向不明的更正只标为待确认，不自动套到任何事项。
5. **各事项能否留在本站**：区分“先补问才能留下的缺口”和“可以稍后补问的缺口”。
6. **补充说明后的重判**：来访者补充关系、签字人或地点后，逐站逐事项比较前后判断。
7. **翻译补记与原话对照**：译文按内容对齐回原话分句；代词、缺句、合并句都会标出。
8. **已接收转介的复核**：逐条摘录判断保留、截取或撤回，说明原安排是否仍然有效，并给出有依据的更正文本。
9. **决定记录**：每次判断的依据、接收对象和变化原因集中列出，便于回查。
10. **词表**：中英练习用语，标明容易混淆的区分点。

## 设计约束

- **事项隔离**：土地与工资分开归类。工资事项的选段不会进入土地站的摘录；一处更正不会改写另一事项的角色或证据。
- **角色隔离**：同一位来访者可以替别人问租地，同时自己的工钱被欠；报告按事项分别记录角色，不把一个事项的身份套到另一个事项上。
- **说话人区分**：`voice` 为接访员或译员时，其原话不进入土地站或务工站的证据摘录；翻译席只接收译文选段，并标明它是翻译补记而非事实。
- **地点区分**：`heardAt` 是录入站，不是事件发生地；“在青涧”这类说法会同时保留两种读法，由接访人员追问。
- **更正保留**：原始说法与更正并列保留；已发出的摘录不静默改写，更正另行通知，并留下依据。
- **翻译对齐**：译文与中文原话按用词对应，而不是按相邻编号；代词所指不明时列为问题，不当作事实。
- **交接可见范围**：整段转出、混入他事项、夹带工作人员说明或转述的摘录都会被要求撤回或截取；只含本事项选段的摘录可以保留。

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `materials.js` | 原样读取三份基础资料，保持既有读取接口 |
| `src/extras.js` | 读取转介、补充与词表；文件缺失时返回空数组 |
| `src/text.js` | 分句、分句位置与列表切分 |
| `src/lexicon.js` | 事项词表、签字/称谓/地点/代问的识别规则 |
| `src/align.js` | 译文句子与原话分句的对齐 |
| `src/analysis.js` | 归类、角色、站点判断、交接复核、重判与决定记录 |
| `src/render.js` | 生成 Markdown 报告 |
| `report.js` | 命令行入口与 `analyse()` 接口 |

词表、站点能力说明和所有访谈记录都是项目内合成资料，仅用于演练。
